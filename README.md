# 企盈智擎 AI 经营分析 MVP

面向中小制造企业的经营分析演示项目。目标是在 **2026 年 10 月 29 日前**完成从企业 Excel/CSV 数据到经营分析报告的演示流程。

## 本次范围

上传文件 → 读取与字段标准化 → 数据清洗与可信度检查 → 订单生产毛利计算 → 异常识别 → AI 解释与建议 → 报告展示。

最低交付包括订单收入、成本、生产毛利和毛利率，以及有证据的异常提示。当前本地模型还提供订单管理利润用于口径验证；财务报表净利润、完整督查任务、复杂机器学习、多行业复制暂不列入本次 MVP。

## 当前状态与技术方向

2026-10-12 已建立独立利润计算模型和本地网页看板 v0.1。实现收入、材料、计件人工、制造费用与期间费用分摊，以及场内暂算利润、生产毛利和订单管理利润。可导入标准 Excel/JSON、追溯费用与计算快照，并导出当前筛选范围。内置数据全部为明确标记的合成数据，尚未通过企业真实样本验收。

本版采用 Python Decimal + 标准库 HTTP 服务 + HTML/CSS/JavaScript，无外部网页资源或 AI 调用。Excel 读写使用可选的 openpyxl。原始企业导出文件需在收到样本后增加字段映射。

### 运行

Windows 双击根目录 `启动看板.cmd`，浏览器打开 <http://127.0.0.1:8765>。或执行：

```powershell
python server.py --port 8765
```

需要 Python 3.10+。如需 Excel 导入导出，执行 `python -m pip install -r requirements.txt`。只在本机监听，不是已上线的公共网站。端口已占用时先打开上述地址，或用 `--port 8766` 启动第二实例。

运行验证：`python -m unittest discover -s tests -v`。

字段、计算边界及模板说明见 [输入格式与使用说明](docs/input_format.md)。计算模块入口为 `profit_model.engine.calculate(dataset)`，与页面及服务分离；现有团队公共接口文档未改动。

## 开始协作

1. 接受仓库邀请，将仓库克隆到本地。
2. 阅读 [协作约定](docs/collaboration.md)，确认任务负责人和模块边界。
3. 拿到样本后共同补充 [数据字典](docs/data_dictionary.md) 与 [计算及校验规则](docs/calculation_rules.md)。
4. A、B、C 共同确认 [模块接口草案](docs/interfaces.md)，再分别实现模块。

## 数据与配置

企业原始数据存放在本地 `data/raw/` 或经授权的受限共享空间。仅将允许共享的脱敏样本或模拟数据提交到 `data/samples/`，在配套说明中标明来源和用途。

如后续模块需要环境变量，可复制 `.env.example` 为 `.env` 并在本地填写。实际密钥、凭证及包含敏感输入的日志不得提交。样本共享授权不自动包含向外部大模型 API 发送数据的授权；接入时确认发送范围。

`.gitignore` 只保护尚未跟踪的文件，提交前仍需检查暂存内容。
