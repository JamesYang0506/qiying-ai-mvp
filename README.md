# 企盈智擎 · 订单动态管理

本工程直接拆分为三个目录，文件通过移动归类，每份文件只保留一处。

| 目录 | 内容 |
| --- | --- |
| 运行文件 | 页面 dist、服务运行包 runtime、启动程序和第三方许可 |
| 开发文件 | 服务端源码 server、脚本、测试、文档、接口样例及开发依赖 |
| 存储文件 | data 内的订单、账号、历史记录，以及 output 日志和调试资料；不提交 Git |

## 启动

安装 Node.js 20 或以上，在本目录双击 **启动网站.cmd**。也可双击运行文件内的启动入口。窗口会显示实际 IP、端口和网址，请保持窗口开启。

已有数据统一读取 `存储文件/data/imports/`，不需要重新注册或导入。AI 模型服务仍需单独运行。

## 开发

日常仍在本工程中修改，前端文件位于 `运行文件/dist/`，后端源码位于 `开发文件/server/`。首次克隆后在本目录执行：

```powershell
npm run setup
npm run build
npm test
```

后端修改后执行 `npm run build`，生成结果直接写入 `运行文件/runtime/`，随后重启网站。不要直接修改生成的服务运行包。Node 开发依赖只安装到开发文件/node_modules。

根目录的 package.json 仅用于转发命令，实际开发依赖及锁文件位于开发文件内。Git 管理目录和 CI 配置留在根目录。

## 数据与备份

网站只写入 `存储文件/data/imports/`。需要另设位置时，可设置环境变量 `QIYING_DATA_DIR` 为 imports 目录的绝对路径。停服后再迁移或恢复数据；不要用代码更新覆盖存储文件。

原开发文档见 [开发说明](开发文件/README.md)，旧文档中的 server、scripts、tests、docs、examples 等路径现在以开发文件为起点；dist、runtime 和启动程序以运行文件为起点，data 和 output 以存储文件为起点。

本次已撤下自动导出命令，正常启动、构建和测试不会创建新的分发副本。
