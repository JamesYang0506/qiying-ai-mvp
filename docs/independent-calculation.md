# 独立成本计算与事后对照

源工作簿适配器从配方单价/用量、分码SOP重量/数量、报价/折扣及逐项费用计算。用 Decimal 保留计算精度，汇总后舍入到分。

- 收入 = （报价 − 每双折扣）× 订单数量。
- 每张材料表的配方均价 = Σ（原料单价 × 配方用量）÷ Σ配方用量。
- 材料费 = Σ（每张材料表的分码重量 × 数量 × 配方均价）。
- 加工费用 = Σ加工单位费率 × 订单数量。
- 毛利润 = 收入 − 材料费用 − 加工费用。
- 行政费用 = Σ行政单位费率 × 订单数量。
- 扣行政费用后参考利润 = 毛利润 − 行政费用。

成本计算表 H5/H10/E9/E10/H23/H24/H32/H33 和两张材料表 B19/B20/K3/D18/E18 不作为输入；即使其他输入公式试图引用这些单元格也会被拒绝。模型结果生成后，才读取 H24/H33 保存值乘订单数量作对照，不执行这两个单元格的公式、不回写计算结果。没有可用保存值时显示无法对照。

审计信息放入 `source_analysis.audit`，随 JSON 导出，包括方法版本、排除单元格、对照和差额。源文件 SHA-256 可供确认输入版本。该信息说明程序计算路径，不能代替原始业务凭证真实性核验。

测试覆盖：修改、删除、循环引用利润/汇总单元格不影响结果；实际费用输入变更影响利润；缺失必要费率保留空值。当前费用含外链缓存，因此独立计算不等于全部成本已独立验证。

待补资料：外链原始费用表及完整分摊分母；含税/不含税报价与折扣依据、出货验收记录；材料采购与领补退料、回收与在制品记录；工资计件/分摊依据和各期制造费用/工时；行政开发资产的分摊范围及其他适用费用；分码不良、返工、补料记录；正式订单号与客户。确认无费用时应明确不适用或已确认零，不用空白代替。
