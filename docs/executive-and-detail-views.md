# 决策首页与详细数据

顶部切换两页。默认进入决策首页；原有精确数据、公式、分摊追溯及四类可信化审查留在详细页。左侧导航分别匹配各页正文顺序。首页“查看依据”进入详细页并清除筛选，以确保来源订单可见。

首页只展示当前源工作簿所对应订单，不作为公司合并报表。金额显示到0.01万元、比例到0.01%；计算、导出和详细页仍保留原始精度。两张饼图均以本单收入为分母，不能相加。

风险提醒优先展示已发现差异，再列费用完整性、税口径和外链来源待核验。已有费用已用于试算，不因缺来源凭证而从参考利润中扣除或遗漏。首页建议基于当前金额和审查规则，包括报价与成本边界复核、大额费用核验、数量差异关闭，不自动认定应接单或拒单。成本整体增加1%的测算是假设收入不变的敏感性情景，非实际预测。

缺少源工作簿分析时显示暂无可用决策概览；不生成默认金额。负值、零收入或缺失数据不绘制误导性饼图。
