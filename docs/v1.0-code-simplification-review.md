## 可直接清理的小项

- app.js render 中的 complete 局部变量计算后未使用，可删除。
- analysis_gateway.py status 函数在当前仓库中未找到调用；实际 /api/ai/status 使用 client.status()。确认没有仓库外调用后可删除该旧占位函数。
- 不删除 prepare_analysis 的 not_configured 分支：模型不可用时仍需准备事实并明确返回状态，现有测试覆盖该行为。
- 演示按钮、样例下载虽在页面隐藏，但仍有程序引用和开发用途；不能按“隐藏”直接判为死代码。可后续统一开发入口策略。

## 不应为精简而合并或删除

1. engine.py 严格核算与 eva_source.py 参考试算的口径边界。
2. Decimal 金额运算、缺失值与零的区别、最大余数分摊及未分摊余额。
3. 原始成本独立计算、禁止原表利润答案进入计算输入、受限公式处理。
4. 查重投入指纹与结果复核的双重检查、旧快照保守兼容、回收站可见性及并发锁。
5. 当前分析与历史回看的分离、模型输出单独保存及事实引用校验。
6. 已有回归测试。特别保留映射/单位校正、分摊尾差变化、部分重复和删除恢复用例。

## 建议执行顺序

第一批：独立格式化、清理确认无用代码、抽取请求/金额/快照裁剪工具。

第二批：整理快照读取与写入，再拆分 HTTP 服务逻辑；保持现有输入输出协议。

第三批：统一前端页面状态和字段配置，优化单次请求中的 Excel 读取；配套隔离浏览器回归。

v1.0 功能开发应在这些整理之后逐项推进。版本名称本身不代表已发布，也不自动授权推送、合并或构建发布包。
