# 利润分层和可信化桌面审查

## 利润分层

生产毛利试算 = 折后订单收入 − 材料成本 − 加工组费用。加工组包括生产工资，不再重复扣工资。

经营净利试算 = 生产毛利 − 已列管理费用 − 已列销售费用（运费）。分别展示新增经营费用、生产成本和累计已列成本；净利仍为费用范围待确认的试算，不能当作已核实财务净利润。

暂沿用源表费用组；开发费用、生产管理工资及资产摊分的归属需复核。分类变动可能改变生产毛利，即使经营净利合计不变。必要费用缺失时保留空值。显示成本按分汇总可能存在舍入尾差。

## 数据可信化

`source_analysis.trust_review` 随本地快照与 JSON 导出保存，`profit_layers` 保存分层金额。状态为核对通过、发现差异、待核验，不给未经证实的真实性百分比分数。

审查覆盖总数量、分码数量、补单差额、日期重复、计算与答案隔离、事后利润对照、文件指纹、外链来源、报价税口径、实际材料耗用、费用期间及分摊、资产与开发费用、分类重叠及净利费用范围。

文件指纹只能说明输入版本；保存利润一致只能说明本次算术一致；日报勾稽一致不能证明已销售。涉及金额为待核验范围，可能重叠，不能视为损失或相加。业务真实性需原始凭证支持。用户已同意电费、天然气费等先用表内成本试算，来源复核在后续进行。
