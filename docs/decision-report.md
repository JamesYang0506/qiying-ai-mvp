# 单订单决策报告

在经营概览、详细数据或理论对照页面点击“一页决策报告”，选择一笔订单，预览后点击“打印 / 保存 PDF”。在浏览器打印窗口选择打印机或保存为PDF，可关闭浏览器自动添加的页眉页脚。

报告包含收入、生产成本、生产毛利与毛利率、经营净利试算或订单管理利润、保存的理论对照、主要预警、待补依据、建议行动及版本定位。

- 报告是重点摘要，预警、待补和行动按重要性选列并标注数量，完整依据在网站对应快照中查看。常规内容按A4一页设计，长订单名或长证据允许续页，不裁切文字。
- 未保存检测时标明未检测；检测读取失败时明确提示，不能据此认定正常。
- 理论对照读取该快照/订单最近保存的检测及其理论、规则和事件，不采用当前全局规则重算。报告页底提供检测和版本编号供核对。
- 历史只读、模拟数据、参考试算、估算利润和未知税口径均保留标识。报告无需模型，也不自动生成已审核业务结论。
- 报告预览只发GET请求，不新增快照、检测、基线或模型建议；打印在独立文档中进行，不包含网站导航及操作按钮。
- 普通数据导出继续提供原有CSV/JSON压缩包，用于核查精确数据。训练资料导出暂缓，仅保留路线图。
