# 标准导入格式与字段口径数据字典

版本：IMPORT-0.2 / A-ORDER-0.2 + AB-TIME-0.2。日期统一 `YYYY-MM-DD`，时间带时区 ISO 8601；业务时区 Asia/Shanghai。金额为十进制字符串，展示按分；数量最多 6 位小数，生产/不良/补产为整数。

## 一、成本 Excel

### 订单信息（字段名在 A 列，值在 B 列）

| 字段 | 单位/取值 | 缺失处理 |
| --- | --- | --- |
| 模板版本 | 固定 `A-ORDER-0.2` | 拒绝导入 |
| 订单ID / 核算子项ID | ≤128 字符 | 必填；首版一个订单只支持一个核算子项 |
| 合同数量 | 双，整数 | 缺失则进度与收入未知 |
| 核算报价 | 元/双 | 缺失则收入、理论毛利未知 |
| 模拟标准重量 | kg/双，>0 | 缺失则理论材料与材料耗用影响未知 |
| 生产覆盖开始 / 结束 | 日期 | 需有序，跨度 ≤3660 天 |
| 预期基线版本 / 数据修订版本 | ≤128 字符 | 必填；每日表必须一致 |
| 时区 | 固定 `Asia/Shanghai` | 其他值拒绝 |
| 是否模拟 | `是` / `否` | 必须明确 |
| 产品 / 客户代号 | 文本 | 展示用 |
| 税口径 | 固定 `模拟报价不拆税` | 其他值拒绝 |
| 收入口径 | 固定 `生产等价` | 其他值拒绝；仅为管理试算 |
| 期初加工/不良 | 首版必须 `0` | 非零期初拒绝 |

### 成本计算（命名 Table `CostParameters`，表头行 34）

| 参数ID | 单位/含义 |
| --- | --- |
| `material_pct` | 报价中材料占比（65% = 0.65） |
| `prep_piece` / `press_piece` | 准备、压制计件单价（元/双） |
| `production_mgmt` | 生产管理费占收入比例 |
| `energy_pct` | 能源费占收入比例（0.4% = 0.004） |
| `company_mgmt` / `admin_pct` | 公司管理、行政占收入比例 |
| `logistics_piece` | 物流费（元/双） |
| `production_loss_budget` / `defect_loss_budget` | 生产、不良损耗预算占收入比例，仅预算模式使用 |
| `other_production_piece` | 其他生产费用（元/双） |
| `finance_piece` | 财务费用（元/双） |

比例类取值必须 0–1；缺失参数导致对应理论项为 null，不按 0 处理。

### 原订单用量

| Table | 字段 | 说明 |
| --- | --- | --- |
| `OriginalRecipe` | 材料编号、原表配方量kg、原表参考单价元/kg | 配方量合计必须 >0；编号唯一 |
| `OriginalSizePlan` | 码号、分码合同量 双 | 分码合计必须等于合同数量 |

理论材料单价由报价材料占比与标准重量校准原表参考单价比例；实际材料为净耗 × 实际单价。

### 补单用量（`SupplementEvents`）

字段：补单记录ID、订单ID、核算子项ID、发生日期、码号、补产数量双、生产关联ID、计入规则、原因。

- 计入规则必须以“已含”开头：补单已计入加工量与净耗，不再追加数量或扣一笔补单损失。
- 关联生产记录必须同日同码，补产数量不得超过当日加工量。
- 不良量与补单量差异只提示（`SUPPLEMENT_DIFFERENCE`），不自动补造。

## 二、每日 Excel

“每日生产”A4 必须以 `AB-TIME-0.2` 开头。

| 工作表 / Table | 关键字段 |
| --- | --- |
| 每日生产 / `DailyProductionCase` | 记录ID、生产日期、码号、当日加工量、当日不良量、当日状态、资料状态、数据可见时间、来源、是否模拟、订单ID、子项ID、基线/修订版本 |
| 每日材料 / `DailyMaterialCase` | 记录ID、发生日期、材料编号、实际净耗kg、实际单价元/kg、材料口径=`actual_net`、资料状态、可见时间、来源 |
| 每日费用 / `DailyExpenseCase` | 记录ID、发生日期、成本类别、费用项目、计价方式=`直接金额`、实际金额元、资料状态、可见时间、来源 |

公共规则：

- `资料状态`：已确认 / 暂估 / 缺失 / 不适用 / 模拟确认。`待补录` 属于当日状态，不计入完整实际。
- `数据可见时间` 不得早于发生日期；历史查询只使用截至选定日期已经可见的记录。
- 零、缺失、暂估、停产、待补录严格区分：留空表示未知；明确的 0 才按 0 计算。
- 每日表的订单ID、子项ID、基线版本、修订版本必须与成本表一致。

## 三、理论与实际口径

| 口径 | 含义 | 计算依据 |
| --- | --- | --- |
| 整单理论目标 | 固定目标，不随当天实际变化 | 合同数量 × 报价 − 整单理论成本 |
| 理想上界（ideal） | 不含额外损耗预算 | 材料、人工、生产管理、能源、其他生产 |
| 预算基线（budget） | 含生产与不良损耗预算 | 理想项 + 两项预算 |
| 当日实际 | 仅选定业务日可见的实际记录 | 当日合格量 × 报价 − 当日实际成本 |
| 累计实际 | 开始日至选定日的逐日累计 | 逐日舍入后相加 |
| 同进度理论 | 与实际相同的累计合格量对应的理论值 | 同一核算器按累计产量重算 |
| 生产毛利 | 收入 − 材料 − 人工 − 制造 − 其他生产 | 未扣管理、销售、财务 |
| 经营利润 | 生产毛利 − 管理 − 销售 − 财务 | 管理核算值，不是审计净利润 |
| 预计完工利润 | 独立预测输入/版本 | 首版未建立，固定为 null |
| 已结算最终利润 | 整单、已结算且资料完整确认 | 导入首版不提供，固定为 null，结算状态 open |

差距定义：页面“少赚” = 同进度理论 − 累计实际；“差距来源”各项为成本实际 − 理论，合计与总差距精确一致（含舍入调整）。补单作为耗用与人工的解释依据，不重复列为损失。

## 四、缺失传播与完整性

| 缺失项 | 结果为 null 的范围 |
| --- | --- |
| 订单数量 / 报价 / 标准重量 | 进度、收入、相关理论项 |
| 期初 | 累计实际与累计产量 |
| 基线参数 / 配方 | 对应理论项；实际仍可计算 |
| 某日生产记录 | 该日及累计产量、收入、实际毛利 |
| 某日某材料净耗或单价 | 该日及累计实际材料、生产毛利 |
| 某日生产类费用（人工/制造/其他生产） | 生产毛利 |
| 某日经营类费用（管理/销售/财务） | 经营利润，生产毛利仍可用 |
| 记录在选定日期尚不可见 | 不计入当日及累计，不视为零 |

`quality.completeness` 分三维：

- `actual`：订单、材料、费用是否完整；
- `baseline`：基线参数与配方是否完整；
- `progress`：生产记录与订单数量是否完整。

整体 `quality.state`：`complete` / `provisional`（含暂估）/ `incomplete` / `operating_incomplete` / `not_started`。

## 五、与 A 模块目标契约的映射

适配层：`server/profit/contract-adapter.mjs`，只映射既有核算结果，不另写公式。

| 契约字段 | 当前来源 | 差异/说明 |
| --- | --- | --- |
| `scope.basis` | 固定 `cumulative` | 当前只支持累计查询；目标契约还支持 `order_total` / `daily` |
| `scope.period_start/end` | 订单开始日 / 选定日期 | 一致 |
| `scope.quantity_basis` | `completed_good` | 仅合格量口径 |
| `scope.currency` | 固定 `CNY` | 导入模板未采集币种，首版均按人民币 |
| `scope.tax_basis` | `ignored` | 模拟报价不拆税 |
| `scope.revenue_basis` | `production_equivalent` | 仅管理试算 |
| `scope.settlement_state` | `open` | 无正式结算流程 |
| `actual/expected.gross_profit` | `cumulative.actual/expected.gross` | 一致 |
| `management_profit` | `cumulative.actual.operating` | 管理核算，不是审计净利润 |
| `forecast_profit/final_profit` | `null` | 首版未建立 |
| `comparison.profit_delta` | 累计 actual − expected | 与页面“少赚”符号相反 |
| `comparison.relative_decline` | 预期毛利率 >0 时计算 | 预期≤0 时为 null |
| `comparison.risk` | `not_applicable` | 风险分级尚未接入；不伪造等级 |
| `comparison.cost_variances` | 材料/人工/制造/其他生产 | 预算模式的损耗预算不在四个成本类别中 |
| `issues` | 缺失与补单差异 | 缺失映射为 `blocking`，差异映射为 `warning` |
| `evidence` | 空数组 | 正式 `evidence_id` 需 B 的快照绑定；原始来源仍在导入 API |
| `snapshot_id` | 调用方传入或本地确定性派生 | 正式环境必须由 B 分配不可变快照 |

## 六、首版不支持（导入前即拒绝）

非零期初、正式税务收入/拆税、多币种、多核算子项、非 Asia/Shanghai、非生产等价收入、未归属的共享制造费用池、正式结算与预测完工利润。扩展前先补数据模型和独立验收案例。
