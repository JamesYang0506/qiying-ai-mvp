# 监测筛选与风险表格改版

依据用户提供的四张参考图，更新订单监测页，保留上一版蓝色顶栏、图表和建议布局。

## 筛选范围

- 顶部改为横向筛选：全部客户、生产状态、全部风险、近 7/16/30 天趋势、订单/产品/客户搜索、重置筛选。
- 默认全部状态、全部客户、全部风险、近 16 天；重置恢复这些条件。日期及对照基线仍可选择。
- 客户、状态、风险、搜索由服务端筛选，概况卡、覆盖、曲线、分布及重点订单使用同一固定版本集合；不是只隐藏列表行。
- 分布图分类及“今日恶化”仍只筛选底部列表，显示可清除的分类标记。
- 搜索有短暂防抖和响应序号保护，快速输入或切换条件时不会让旧响应覆盖新选择。

## 订单监测表

列为订单/产品、客户、生产进度条、预期毛利率、当前毛利率、较预期偏差、较昨日变化、风险等级、查看分析/依据。

- 预期和当前毛利率为同进度累计口径；偏差为实际减理论，按百分点显示。
- 较昨日继续采用既有的前后日**当日毛利率**变化，保留迟录/修订等不可比较原因，不把累计差距增长当成今日恶化。
- 默认风险优先，支持偏差、较昨日及订单号排序，同值按订单 ID 稳定排序。
- 每页 6 笔，上一页、数字页码、下一页和显示范围计数；查看分析携带监测日期、修订及基线模式。
- 隔行浅色、低调的进度条、亏损/下降红字、风险色块参照用户图片；未知显示横线。

## 风险与状态

风险由 `server/profit/monitor-risk.mjs` 使用项目已确认的同进度毛利率相对下降规则：下降不超过 10% 正常、不超过 20% 注意、不超过 30% 重点，超过 30% 严重；实际优于理论显示优于预期。未知实际、未知基线、预期非正分别为数据不足、缺少基线、不可评级。金额仍由原 A 核算器提供，没有新写利润公式。

监测行和 A 契约适配器使用同一个风险分类函数，版本 `RELATIVE-MARGIN-1`；当前导入规则版本升级为 `IMPORT-RULES-0.3`。旧持久化快照不覆盖。

生产状态优先按当前资料的业务范围和累计合格量显示：未开工、生产中、已完工或资料不足时待确认。“已完工”指生产数量已达到合同量，不代表财务结算完成。

## 移除内置演示

删除所有内置演示入口与生产页面中的演示数据加载；旧 `#demo` 地址回到监测页。订单明细导航也改为真实已导入订单，AI 入口只说明真实服务未接入，不再列出虚构订单。原来的合成数据与计算参考已从 dist 移到 tests/fixtures，仅用于回归，不在应用中加载。启动器也改为检查新的监测页文件，并识别新版服务，避免复用仍在运行的旧演示服务。

## 验证

- 88 项 Node 测试通过，包括风险阈值、缺项分离、范围汇总一致性和启动入口。
- 接口契约的 81 个 Schema、23 个操作和 7 份示例通过校验。
- 浏览器验证客户/风险/搜索/重置、六行分页、数字页码、排序、分布列表筛选、固定依据、旧响应保护和演示移除。
- 已导入订单的概览、差距归因、明细和下钻仍通过浏览器验证。
- 桌面和 390px 窄屏布局已检查；截图仅为临时合成测试订单，未复制真实业务数据。

服务端有改动，已重建 runtime。使用原目录时须关闭旧服务窗口、重启网站并 Ctrl+F5 刷新。

## 空金额修复

默认状态改为全部状态，避免已完成的导入订单全部被默认筛除。筛选无匹配时明确显示已导入数量与调整建议；有订单但不可比时提示展开缺项原因。
