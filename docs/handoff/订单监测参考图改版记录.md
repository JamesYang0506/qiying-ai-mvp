# 订单监测参考图改版

依据用户提供的蓝色经营总览参考图，调整默认 `#monitor` 页面。

## 界面变化

- 新增通栏蓝色品牌顶栏、深蓝侧栏和页面专属导航主题。
- 四张指标卡采用图标色块、加大金额和状态强调；金额较长时保留完整内容。
- 上排为实际/同进度理论毛利面积趋势图与当日毛利率分布环形图。
- 下排为今日重点核查 TOP 5 表格与选中订单的规则核查建议；“查看全部”联动列表筛选。
- 全部订单保留搜索、分类、分页、单订单分析和固定版本依据入口。
- 日期、基线、趋势窗口及数据来源集中在监测范围工具条；覆盖与信息截止说明可展开查看。
- 手机端采用紧凑顶栏、图标导航、双列指标卡和纵向图表，表格支持横向查看。

只参考布局、颜色和信息层级，没有使用图片中的示例金额、企业账号、通知或任务数据。指标口径和核算结果保持不变；建议仍明确标记为规则生成，不冒充 AI 回答。

## 文件

- `dist/monitor-dashboard.js`：监测页展示组件与品牌顶栏。
- `dist/monitor-dashboard.css`：独立视觉主题，导航和外壳样式只在监测路由生效。
- `dist/monitor-workspace.js`：沿用查询、筛选、选中状态、弹窗和旧响应保护，调用展示组件。
- `dist/app.js` / `dist/index.html`：主题及顶栏挂载。
- `dist/charts.js`：增加可选面积填色；默认关闭，已有单订单图表继续使用原样式。
