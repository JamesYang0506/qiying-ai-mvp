# C模块：场景回答规则与验收清单

版本：讨论稿v0.1；日期：2026-10-19。

用途：供三人审核场景识别、管理者回答和验收方式。配套《C模块管理者决策问答初稿》，本文件制定行为规范，不改动网站、利润公式或模型提示词，也不是已经实现的规则引擎或已审核训练集。

## 一、统一回答原则

管理者首屏以3～5句为目标，顺序为：**结论 → 最多3项关键依据 → 建议行动 → 必要的限制说明**。方案详情再展开，避免输出JSON、程序字段、内部记录编号和公式。订单名称与业务日期保持可见。

有金额的现有样本示例，除特别注明外，均为2026-09-30、理想理论基线的模拟结果，来自现有6个盈利/亏损压力样本，不是真实企业当前经营结论。万元为近似展示。其他示例是边界情境，不假称已有对应表格。

### 1. 首先检查能否回答

1. 确认问题所指的订单、业务日期、修订版本和基线；不明确且影响结论时，先用一句话确认。
2. 检查问题所需指标是否完整。缺人工成本可阻断生产毛利；只缺管理费用时，仍可解释已知生产毛利，但不能给出完整经营利润。
3. 同一指标必须保持日期、单位、含税与费用口径一致；相互矛盾、无法核对的记录进入核查场景。
4. 对于未开工、无正收入、理论毛利非正等情况，不强行计算毛利率下降比例。
5. 多订单摘要不完整或被截断时，不能声称完成全量排序，也不能把摘要子集的合计称为全部订单合计。

### 2. 场景可以组合，但行动要聚焦

先处理影响结论的数据与范围问题，再识别经营状态，再选择有数据支持的差额项，最后给建议。例如“仍盈利但偏差严重＋材料价格差额最大”可以同时成立，不能只选一个标签而丢掉重要信息。

主回答优先围绕1个最重要行动展开，必要时提供最多2个备选动作，不要求所有回答凑齐三个原因或三套方案。

成本项按**已知正差额**选重点；负值表示节省，舍入不作为经营原因，预算预留也不是实际生产损失。存在抵消项时，各项正差额之和可能大于净差额，不能为凑占比而改数。

### 3. 沿用网站已有风险规则

下列比例仅在实际生产毛利、同进度理论毛利和正收入已知、理论毛利为正、比较口径一致时适用：

`相对下降 =（同进度理论毛利－实际生产毛利）÷同进度理论毛利`。

| 相对下降 | 现有网站标签 |
| --- | --- |
| 小于0 | 优于预期 |
| 0～10%，含10% | 正常 |
| 大于10%至20%，含20% | 注意 |
| 大于20%至30%，含30% | 重点 |
| 大于30% | 严重 |

这是现有项目规则，不是新增的行业标准。这里的相对下降不是下降了多少个百分点；回答不得混淆两者。亏损还需单独明确说明，不能只输出“严重”。

## 二、14张场景规则卡

### SC01｜正常盈利或优于预期

- **适用条件：** 生产毛利为正；同进度比较有效；现有风险标签为“正常”或“优于预期”。不自动代表质量、交期或经营利润也正常。
- **管理结论：** 当前毛利表现接近或优于所选理论基线，可以持续监测。
- **关键依据：** 累计生产毛利、毛利率或相对偏差；如经营利润已知且为负，必须同时进入SC13。
- **建议行动：** 维持必要监测；有小额差异时先做针对性复核，不直接建议大范围整改。
- **待确认：** 企业实际目标、其他风险指标及经营费用是否齐全。
- **回答示例：** “P01累计生产毛利18.99万元，毛利率19.78%，与同进度理想理论相差约0.63万元，按当前规则属于正常范围。建议持续监测，并复核材料用量的小幅差异；不必仅凭存在差额就大范围整改。”
- **禁止说法：** “所有指标均正常”“完全没有风险”“低于理想值就必须整改”。

### SC02｜仍有毛利，但明显低于预期

- **适用条件：** 生产毛利为正，同进度理论毛利为正且比较完整；相对下降大于10%。具体等级沿用网站规则，不另外发明阈值。
- **管理结论：** 当前仍有生产毛利，但尚未达到预期表现；正毛利不等于整体经营盈利。
- **关键依据：** 实际生产毛利、同进度差额、最大的已知成本差额。
- **建议行动：** 针对最大差额项安排核查，核实后再评估工艺、采购或后续报价。
- **待确认：** 差额项是否有明确来源、是否存在缺项或不一致口径。
- **回答示例：** “P02累计生产毛利15.62万元，但比同进度理想理论少18.15万元。建议列入重点核查，先检查材料净用量与人工报工。仍有毛利，不代表已达到预期。”
- **禁止说法：** “赚钱就不需要处理”“盈利不足就是已经亏损”“差额全部可以追回”。

### SC03｜已经出现生产亏损

- **适用条件：** 已知累计生产毛利小于0。等于0称为持平，不称为亏损；成本不齐导致的未知值不视为负数。
- **管理结论：** 明确说明生产毛利为负及其金额，再说明有依据的主要差额项。
- **关键依据：** 累计生产亏损金额、最大的成本差额；只在已知时补充经营利润。
- **建议行动：** 建议安排专项核查。仍在产时测算剩余生产的可避免成本、后续收入及交期影响；已完工时转为复盘与后续订单改进。
- **待确认：** 订单是否仍在产、合同约束和剩余生产损益。没有这些条件，不替管理者决定停工。
- **回答示例：** “L02截至9月30日累计生产亏损7.69万元，材料价格差额约22.34万元，是最大成本偏差。建议采购先核对价格依据，并评估后续采购和报价；该样本已完成计划产量，应进行复盘，不能把历史亏损当成待停工的生产任务。”
- **禁止说法：** “立刻停工”“停止付款”“再生产一双一定亏一双”“累计亏损等于最终净亏损”。

### SC04｜材料价格是主要差额项

- **适用条件：** 同口径成本分解中的材料价格差额已知、为正，并为最大或明显重要的正差额。不能仅因材料总金额变大就判断采购涨价。
- **管理结论：** 利润偏差主要体现在材料价格，优先核价。
- **关键依据：** 材料价格差额，以及可比材料的单价或报价依据；没有单价明细时不编造涨价百分比。
- **建议行动：** 建议采购与财务核对实际计价及基准；确认后评估后续议价、替代供应或重新报价。
- **待确认：** 税、单位、材料规格、价格有效期、可替代性、合同可调范围。
- **回答示例：** “L02的材料价格差额约22.34万元，是当前最大的成本偏差。建议采购先核对计价与报价依据，再评估后续议价或替代采购。替代方案需质量验证，改善金额待测算。”
- **禁止说法：** “采购人员失误已确定”“供应商欺诈”“换供应商必然节省22.34万元”。

### SC05｜材料用量或不良相关差额突出

- **适用条件：** 材料用量差额已知且为重要正差额；不良只有在记录可核对时作为关联线索。未验证时不把两者写成唯一因果关系。
- **管理结论：** 优先核对净用量和质量记录，确认后再优化工艺或配方。
- **关键依据：** 用量差额、累计合格量或已知不良率；只展示与当前问题相关的指标。
- **建议行动：** 生产、质量与仓储核对领退料、净耗、单重及不良补产，再做小批验证。
- **待确认：** 计量与单位是否一致、补单是否已含、具体不良工序及质量要求。
- **回答示例：** “L04材料用量差额约16.16万元，是主要成本差异。建议先核对领退料、单重和补产记录；确有优化空间再做小批工艺或配方试验。现有数据还不能直接认定存在浪费。”
- **禁止说法：** “工人浪费已经证实”“直接减料”“不良量与补单量都再加一次成本”。

### SC06｜人工成本差额突出

- **适用条件：** 人工差额已知且为重要正差额；比较期间、费用范围和产量口径相同。总人工费用增加不自动等于单位效率下降。
- **管理结论：** 人工成本需要核查，但先区分报工、费用分摊和生产组织问题。
- **关键依据：** 人工差额、合格产量、可用的单位人工成本；没有工时记录时不虚构效率结论。
- **建议行动：** 生产与财务核对班组费用、有效工时、换模和排产，评估后续合批或班组安排。
- **待确认：** 固定/计件费用、工时记录、相似订单交期、调整对质量与交付的影响。
- **回答示例：** “L03人工差额10.20万元，累计合格量3万双，人工是最大差额项。建议先核对班组费用和排产，再评估后续相似订单能否合批。不能仅凭成本差额认定人员效率不足。”
- **禁止说法：** “直接裁员”“人员效率下降已证实”“调整排产没有交期风险”。

### SC07｜能耗成本差额突出

- **适用条件：** 能耗差额可独立识别、已知且为重要正差额。只有制造总费用时，不强行拆出电费；只见总能耗增加时，先核对产量变化。
- **管理结论：** 优先核对能耗计量与单位消耗，确认后再安排设备和工艺核查。
- **关键依据：** 能耗差额、同口径产量或单位能耗、已记录的计价变化。
- **建议行动：** 设备、生产与财务核对计量、待机、开机安排和分摊依据；存在异常再制定验证措施。
- **待确认：** 电价、计量范围、设备工况和订单间费用分摊。不能凭此认定设备故障。
- **回答示例：** “当前记录提示能耗成本存在偏差，建议先核对计量与费用分摊，并比较单位产量能耗。确认偏差后，再安排设备与开机工况检查。现有信息还不能确定设备发生故障。”（边界示例，无虚构金额。）
- **禁止说法：** “一定是设备老化”“关机即可节省某个金额”“制造费用全部是能源”。

### SC08｜关键数据缺失

- **适用条件：** 用户所问指标所需的事实或费用缺失。按指标判断，不把某个维度缺失扩大为全部指标都不可用。
- **管理结论：** 直接指出哪项结论暂不能可靠给出；仍可展示不受影响的已确认指标。
- **关键依据：** 缺失内容、涉及日期、受影响指标。未执行的补充措施不写成已完成。
- **建议行动：** 建议相关数据负责人补齐，再重新核算；不将空白、未知值或缺失日期当作0。
- **待确认：** 是未录入、实际为0，还是本来不适用；这些状态不能相互替代。
- **回答示例：** “当前生产毛利可查看，但管理费用尚未齐全，暂不能确认完整经营利润。建议财务补齐对应期间费用后再复核。不能根据现有生产毛利直接判断最终盈利。”（边界示例。）
- **禁止说法：** “没填就是没有成本”“先按0给出正式利润”“缺管理费所以加工量也未知”。

### SC09｜数据矛盾、迟录或修订影响比较

- **适用条件：** 记录相互矛盾，或比较期间存在迟录、整套修订而无法可靠分离经营变化。若仅修订无关字段，不自动声称所有利润变化都失效。
- **管理结论：** 先说明比较受资料变化影响，不能直接解释为经营恶化或改善。
- **关键依据：** 受影响的业务日期、字段和版本关系。管理者首屏用自然语言说明，内部版本编号放详情。
- **建议行动：** 先核对录入、补单包含关系、迟录与版本差异，固定同口径后重新比较。
- **待确认：** 是否有足够记录把数据修订与真实经营变化分开；当前整套替换导入不具备完整字段级修订解释能力。
- **回答示例：** “本次利润变化包含补录或资料修订，暂不能全部解释为生产经营变化。建议先核对受影响日期和记录，再做同口径比较。”（边界示例。）
- **禁止说法：** “数字变了就说明经营变差”“所有差额都是现场新增损失”“新版本一定更准确”。

### SC10｜指标改善或整改后的改善迹象

- **适用条件：** 两段可比期间的单位成本、毛利率或不良等指标确有改善，且有可核对数据。只有累计利润增长，不足以进入此场景；没有整改记录，不称为整改效果。
- **管理结论：** 先说观察到的改善，区分“指标变化”与“已经验证的措施成效”。
- **关键依据：** 前后同口径指标、期间及与之对应的措施记录；产品组合和版本变化需说明。
- **建议行动：** 建议持续观察；需要推广时先核查质量、交期及可复制性。
- **待确认：** 措施实施时间、影响范围、对照条件、其他影响因素。即使时间先后成立，也不自动证明因果关系。
- **回答示例：** “目前单位成本和毛利率出现改善迹象，建议继续跟踪。还需核对期间、产品组合及措施记录，才能判断改善是否来自本次调整。暂不建议仅凭一段改善就全面推广。”（待补真实前后对照素材。）
- **禁止说法：** “措施已经证明有效”“累计毛利增加就是工艺改善”“已经实现预计节省”。

### SC11｜多订单同时异常

- **适用条件：** 已明确订单集合与业务日期，数据足以支持该集合的比较；摘要截断时只提供已见子集的线索，不声称全量排名。
- **管理结论：** 给出有限且有理由的核查清单，优先回答先看谁，不一次铺满所有订单。
- **关键依据：** 排序范围、日期、排序标准和每单核心风险。未开工及已完工订单分别说明，历史复盘不冒充当前在产预警。
- **建议行动：** 资料不足订单单列待核查；资料完整订单可先按生产亏损金额从大到小列出，再按现行风险等级及差额查看其余订单。用户指定其他标准时，明确按其标准排序。
- **待确认：** 当前上下文是否完整覆盖请求集合、是否采用同一基线、是否混入不可比较指标。有限摘要下不能报告“全部订单无异常”。
- **回答示例：** “在这6个样本中，按9月30日累计生产亏损金额，优先复盘L02、L01、L04，分别亏损7.69、3.38和3.25万元。建议采购、质量和生产负责人分别核查价格、不良与用量。这是所选样本范围的历史复盘顺序。”
- **禁止说法：** “这就是全公司的风险排名”“截断后的10单代表全部24单”“按少赚差额排序却称为亏损排序”。

### SC12｜尚未开工

- **适用条件：** 业务日期早于订单开工日期，并且没有需要另行解释的实际开工记录。生产期间停工或实际0加工不是未开工。
- **管理结论：** 尚无已发生生产表现，不能评为实际盈利或亏损；可单列理论值。
- **关键依据：** 所选日期、计划开工日及实际记录状态。
- **建议行动：** 关注开工准备和排期，待实际记录形成后再判断利润。
- **待确认：** 计划是否更新、是否存在早开工或日期错误；存在矛盾则先按SC09处理。
- **回答示例：** “所选日期早于开工日，目前没有实际生产表现可供判断。可以查看理论利润，但不能把它当作已赚金额。建议先关注开工条件与排期。”
- **禁止说法：** “未开工也已经亏损”“理论最大利润就是实际利润”“未开工和停工是一回事”。

### SC13｜有生产毛利，但经营利润为负

- **适用条件：** 生产毛利为正、经营利润已知且为负。管理费用缺失时不能判为经营亏损。
- **管理结论：** 明确生产环节有毛利，但尚不足以覆盖已记录经营费用，不概括为整体赚钱。
- **关键依据：** 同一日期的生产毛利、经营利润，必要时列已确认的经营费用。
- **建议行动：** 财务与经营负责人核对费用范围，评估报价、订单结构和后续执行；仍在产时，停工决策须另算剩余损益。
- **待确认：** 费用分摊口径、期间、是否完整结算和后续未发生费用。
- **回答示例：** “L02截至9月15日生产毛利仍为正1.47万元，但累计经营利润为负1.81万元。建议同时复核原料价格与经营费用，并测算后续执行方案。当前有生产毛利，不代表整体经营盈利。”
- **禁止说法：** “有毛利就赚钱”“经营利润等于审计净利润”“经营亏损就必须停工”。

### SC14｜累计差额扩大，但未证明单位表现恶化

- **适用条件：** 同一版本、基线和范围下，生产规模与累计差额同时增加，单位成本或毛利率没有可证实的明显恶化。若不能同口径比较，先使用SC09；若单位指标确已恶化，明确说明，不使用本场景淡化风险。
- **管理结论：** 累计差额增加可能随生产量累加，需要结合单位指标判断。
- **关键依据：** 两个日期的累计毛利和差额、同口径单位指标或毛利率。
- **建议行动：** 跟踪单位成本与毛利率，保留已有偏差核查；不能因为没有继续明显恶化就称偏差已经解决。
- **待确认：** 资料修订、产品结构和费用计入口径是否变化。
- **回答示例：** “P02从9月15日至30日，累计生产毛利由8.01万元增至15.62万元，少赚差额由9.30万元增至18.15万元，但两个日期累计毛利率都约8.6%。差额随生产累加，不足以说明单位盈利明显恶化；原有成本偏差仍需核查。”
- **禁止说法：** “累计差额翻倍，经营就恶化一倍”“累计利润增加，问题已经解决”。

## 三、跨场景的决策限制

| 管理者追问 | 回答要求 |
| --- | --- |
| 提价多少 | 先取得可调整订单量、未来成本、目标利润及合同范围；缺条件时不报涨幅 |
| 能挽回多少利润 | 区分历史差额与未来可避免成本，说明剩余量、措施幅度与实施费用假设 |
| 是否停工、减员、替换材料 | 提供比较与待核查条件，不自动执行；交期、质量、合同影响不能忽略 |
| 是否比行业差 | 只有可靠且同口径行业数据时才比较，不把效果图示例值当行业基准 |
| 最终利润是多少 | 未提供正式结算时明确未知，分别展示已知生产毛利和经营利润 |
| 报工是0还是没填 | 0、未知、不适用分别处理；0收入下不计算实际毛利率 |
| 补单是否额外增加产量 | 按已含/未含规则核对；当前标准样本为已含记录，不能重复计算 |
