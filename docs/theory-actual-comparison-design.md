# 理论基线与实际对照预警：功能设计草案

日期：2026-10-14。用户已授权实施，首版功能已实现；使用范围与验证见 [实现说明](theory-comparison.md)。用户已确认理论基线同时支持导入已有 Excel，以及网站填写理论投入后计算生成；首版主要关注生产毛利率。本文仍保留后续设计方向，按产品/订单覆盖阈值、单日/连续规则、预计完工利润和自动成本归因尚未实现。

## 已确认的首版利润口径

生产毛利 = 同范围收入 − 生产成本；生产毛利率 = 生产毛利 / 同范围收入。生产成本包括材料、直接人工、加工/制造及其他适用生产成本，需确认项目间没有重复归集。管理、销售、财务等经营费用不参与首版毛利率预警；经营利润可作为后续扩展。

核心对照指标为理论生产毛利率、可比实际生产毛利率，以及“理论毛利率 − 实际毛利率”的下降百分点。毛利仍为正但低于预期也可触发预警；是否触发以及严重程度由已确认规则决定。原有源表参考试算仍显示试算标记，不能改称已核实实际毛利。

## 首版暂定阈值

用户暂时没有企业阈值依据，已授权先使用临时数值，后续获得具体数据再修改。以下为试运行配置，不是企业已确认标准，也不是统计推导结果。

| 规则 | 黄色提醒 | 红色严重预警 |
|---|---|---|
| 毛利率较理论下降 | 下降达到3个百分点 | 下降达到5个百分点 |
| 累计不良率 | 达到3% | 达到5% |

两个等级均包含临界值；达到红色条件时只显示该指标的红色等级，不重复显示黄色。毛利和质量分别判定，订单摘要取当前已触发规则的最高等级；存在无法比较的指标时仍显示待补事项，不能被其他指标的正常状态掩盖。

建议质量观察量暂定为累计生产100双（其他产品按相同计量口径100件），并允许配置。低于观察量仍展示产量、不良数量和不良率，但标记“样本较少，暂不判定等级”，不能显示正常。该观察量是产品试运行防抖配置，不代表统计显著性或质量验收抽样标准。单日规则及连续超标规则首版暂不启用。

每笔订单的理论毛利率仍需导入或计算，不能用上述阈值代替理论目标。最低毛利率底线暂不启用，避免给不同产品套用没有依据的绝对底线。缺少可比利润口径、完整范围或理论基线时，毛利规则显示无法比较；质量在分子分母明确时可以独立判断。

设置页显示“暂定阈值 · 待企业数据校准”，允许修改提醒/严重阈值及质量观察量，记录修改时间、规则版本和暂定/已确认状态。新规则用于后续检测或显式重新检查；历史预警保留原阈值和结果。临时阈值产生的预警用于提示核查，不直接作拒单、停产或损失认定。

## 1. 目标

为每笔业务订单建立接单前理论基线；实际生产数据更新后，发现利润明显低于预期、不良率超过允许范围等情况，并给出差值、触发依据和待处理事项。仍然盈利的订单也可能出现利润偏低预警。

现有原始及模拟数据可作为实际侧输入来源，但需保留真实/模拟标记，以及实际记录、BOM推算、暂估费率等证据状态。源自现实情况的模拟数据仍属于模拟，源表参考试算也不因此变为已核实实际利润。

## 2. 推荐产品流程

1. 创建理论基线：选择已有理论 Excel 导入，或填写数量、报价、折扣、理论材料和人工等成本，由网站计算金额及利润率。
2. 确认业务订单/批次、理论版本、利润口径、数量单位、费用范围和税口径，绑定到订单。
3. 配置预警标准并确认启用；缺少标准的规则显示“待设置”，不默认为通过。
4. 导入或更新实际数据，保存实际快照后重新执行对照。
5. 在经营概览查看预警，在“理论与实际对照”查看指标、费用差异、趋势及依据。
6. 处理预警、备注原因；后续数据更新后判断持续异常、升级或恢复。

初版在数据成功导入/更新时检测，也支持手动重新检查。尚无ERP或日报自动接入，不能承诺未收到新数据时发现现场变化；页面显示最近数据截至时间和最近检查时间。

## 3. 理论利润表

| 字段组 | 建议内容 |
|---|---|
| 身份与版本 | 业务订单号、批次、产品、客户、基线编号/版本、制定时间、适用日期、来源 |
| 收入假设 | 订单数量、计量单位、报价、折扣定义及金额、税口径、理论收入 |
| 成本假设 | 材料、人工、加工/制造、其他生产成本；管理、销售等经营费用按适用范围列示 |
| 利润目标 | 首版必备理论生产毛利率；有完整收入成本时计算理论毛利金额，经营利润目标留作后续扩展 |
| 质量目标 | 目标不良率、容许上限、统计对象和分母口径；可选分码/工段标准 |
| 计算依据 | 公式版本、单位、成本来源、缺失项和确认状态 |

仅有利润比例的旧理论表允许作为“比例目标基线”，支持同口径利润率对照；没有收入/数量/成本依据时，不反推整单目标利润，不生成虚假的费用差异解释。另附质量标准后可启用质量规则。

导入预览区分“表内目标值”和“网站独立复算值”。二者冲突时提示核对，不能默默覆盖，也不能将实际结果或原表利润答案反算成理论成本。未知理论成本保留缺失状态。

已确认基线保留版本，不随实际成本自动更新。修订后产生新版本并声明生效范围；历史对照始终记录当时使用的理论版本及规则版本。

同款不同订单不能只按款号自动绑定。现有 SRC-款号 不足以区分真实业务订单，需补充订单号/批次，或明确人工绑定；关联不唯一时阻止自动对照。

## 4. 对照指标与规则

首版统一使用生产毛利/收入计算毛利率。仅有经营利润率的理论表不能直接作为毛利率基线；若不能取得生产成本或毛利目标，提示补充依据。

| 指标 | 差异与触发方式 |
|---|---|
| 毛利率偏低 | 理论毛利率 − 可比实际毛利率；下降达到配置的百分点阈值 |
| 最低毛利率底线 | 可比实际毛利率低于配置的最低值；与理论偏离规则独立 |
| 利润金额不足 | 仅限相同业务、数量、期间、收入成本范围，比较理论与实际利润金额 |
| 累计不良率 | 累计不良数量 / 同口径累计生产数量；超过明确的容许上限 |
| 不良率偏高 | 实际不良率 − 理论不良率；增加达到配置的百分点阈值 |
| 当日质量波动 | 当日不良/当日产量超过当日标准；要求配置最小观察数量，避免少量投产误报 |
| 分项成本超出 | 具有可比数量、归属及期间依据时比较材料、人工等分项；提示可能贡献，不直接宣称因果 |

百分点与相对变化率分开：20%降到14%是下降6个百分点，相对下降30%。初版建议用百分点做主要阈值，以免误读；理论值为零/负值时不使用相对下降比例。收入不大于零时不计算利润率，单独提示收入异常或无法比较。

不良数量必须明确是首次不良件、报废件还是含重复返工的事件次数；目标与实际分母须一致。沿用目前日报“不良/生产”时标注该定义，不能自动当成最终报废率或材料损失。

阈值采用企业/产品默认值与订单覆盖值，记录来源和确认状态。黄色提醒、红色严重预警的阈值、最小观察量及是否要求连续超标均可配置；首版暂定值见上文，没有依据时不标为企业标准。数据缺失、不可比与超标分开呈现。

说明性模拟案例：理论毛利率20%、实际16%，下降4个百分点，按暂定规则为黄色提醒；实际14%则下降6个百分点，为红色预警。累计生产1000双、不良50双，不良率5%，按暂定规则为红色预警。订单目标和观测值为演示数据，规则采用上述临时配置。

## 5. 生产进行中的可比性

整单理论预算与当前已发生费用不可直接比较为“实际利润”。按以下顺序判断：

- 完工/结算且范围完整：对照整单最终结果。
- 生产中且收入、成本和进度范围一致：显示“过程同范围对照”，明确数量、截至日期和已确认/暂估成分。
- 具有剩余数量及剩余成本测算依据：另列“预计完工利润”，明确估算，不能称已实现利润。
- 缺少上述依据：财务规则显示“暂不可比较”，仍可在统计口径有效时检查质量。

如按实际数量调整理论预算，需区分固定成本与变动成本，不将整单固定费用机械地按产量同比缩放。理论基线数量不被覆盖，调整后的可比预算单独展示。

## 6. 页面与提示

经营概览增加理论目标、最新观测值、差异和状态摘要。新增“理论与实际对照”区域：顶部选择订单、理论版本、实际快照和截至日期；中间对照表；下方利润/不良率趋势、分项成本和预警处理记录。

对照表列：指标、理论目标、可比实际/过程试算、差值、阈值、状态、依据。实际侧含暂估成分时持续显示试算标记。趋势至少需要多个实际观测点；单次导入只展示当前对照，不伪造趋势。

预警卡显示订单、异常指标、目标/实际/差异、触发规则、数据截至时间、影响范围和核查入口。利润偏低与质量偏高并列呈现；同一订单可以同时触发。未知事项放入“待补依据”，不混为已发现经营异常。

建议处理状态与检测状态分开：检测为正常/提醒/严重/无法比较；处理为待处理/已确认/处理中/已关闭。人工已确认不自动消除仍存在的异常。新观测恢复后记恢复时间；重复导入不重复创建相同事件，持续异常更新事件，恢复后再次触发记新一轮。

## 7. 技术落点（建议，未实现）

- 新增理论基线模块：输入校验、计算、版本与订单绑定。
- 新增对照模块：口径检查、可比范围选择、Decimal差异计算和规则判断。
- 新增预警记录模块：事件持续/升级/恢复、人工处理、依据与规则版本追溯。
- 复用现有快照、历史和导入框架，实际计算结果保持独立；理论基线和处理记录另存，避免改变原始实际快照。
- 对照记录关联 business_order_id/batch_id、baseline_id/version、actual_snapshot_id、rule_version 和数据截至时间。理论版本或规则变化时重算得到新对照记录，保留旧记录。
- 现有可信化继续报告数据一致性和依据缺失；经营偏离预警单独列示。模型可解释已计算的差异，预警触发不依赖模型在线。
- 理论数据、规则和预警记录与企业快照一样属于本地业务数据，纳入备份和Git忽略范围；实现时再明确目录。

## 8. 首版验收场景

覆盖正常、仍盈利但偏低、实际亏损、质量超标、同时触发、恰好达到阈值、零收入/零产量、缺失基线/阈值、数量税口径不一致、过程数据不完整、模拟数据、同款不同订单、基线修订、历史回看、持续异常去重、恢复后再触发、重复及延迟日报。

理论修改不能改写已保存实际结果；实际更新不能覆盖理论基线；单次异常不凭空归因。不修改企业原表来消除偏差。

## 9. 尚需确定

1. 企业理论表样例及其费用定义是否能支持已确定的生产毛利率口径。
2. 后续企业质量容许范围和毛利偏离依据，用于校准已获授权使用的临时阈值；质量最小观察量100及暂不启用单日规则为建议设计，仍待整体设计确认。
3. 生产中的费用数据能否按日期/批次提供，剩余成本是否有可靠测算依据。
4. 正式订单号与批次的提供方式，以及首次上线如何绑定现有 SRC-款号 数据。
