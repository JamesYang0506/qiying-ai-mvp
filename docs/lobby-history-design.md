# 大厅与历史订单分析设计

确认日期：2026-10-14。

## 目标

打开网站默认进入大厅，提供订单分析和历史分析记录两个入口。订单分析沿用现有经营概览、详细数据、智能订单分析页面。历史记录允许按订单选择已保存的分析版本，查看当时的利润、成本、可信化结果及已保存的模型建议。

## 交互

- 大厅展示两个主入口及本机历史记录概况。
- 分析页面提供返回大厅、查看历史和返回当前分析的入口。
- 历史按订单汇总，支持编号、产品、客户搜索及模拟/导入数据筛选。
- 每个订单可选择分析时间不同的版本；卡片显示该版本利润和数据状态。参考试算与严格核算明确区分，未知金额不显示为零。
- 打开历史仅展示所选订单。页面持续提示历史时间与版本；不会重算、覆盖当前记录或自动调用模型。
- 历史中的模型结果仅展示与所选订单及快照一致的已保存结果。重新发起分析需显式操作。
- 当前没有历史数据时展示空状态，坏文件跳过并提示数量，不阻止正常记录浏览。

## 数据与接口

复用现有本机 JSON 快照，不引入数据库。增加历史摘要与单订单快照读取接口；过滤 latest.json、非快照文件及不合法路径。原始快照、当前 latest.json 和模型记录保持只读。历史读取按订单过滤 costs、allocations、issues 及 source_analysis，避免出现其他订单内容。

## 验证

后端验证多版本汇总、单订单隔离、模拟标识、试算金额、坏文件容错、非法路径拒绝及读取不改写。浏览器验证默认大厅、历史搜索、版本切换、历史详情、返回大厅及返回当前分析，并检查小屏布局。

## 当前版本保存

大厅开发前保存现有代码和此设计为本地提交，并以 checkpoint/pre-lobby-20261014 标记。企业数据、计算输出和模型权重仍不进入 Git。
