# 理论毛利对照与预警：v1.0开发版使用说明

本功能已实现于本机源码网站，尚未构建或发布新的下载包。

## 使用步骤

1. 正常导入订单实际侧数据，进入新增的“理论与实际对照”页签。
2. 选择订单，点击顶部“导入 / 填写理论利润表”打开编辑面板。可以填写毛利比例目标、整单成本，或使用新增的报价比例核价（method=quote）。报价核价输入数量、单价，各项报价成本百分比，以及备料、油压两项每双计件单价，由网站独立计算计划生产毛利。比例以报价收入为基数，按0～100百分数输入；人工空白不能保存，明确无需该人工时允许填0。计划核价独立于实际资料，不反推或改写实际成本。
3. 已有理论Excel可上传自动识别，也可下载公开模板填入。支持公开键值模板、带标题和空行的键值布局、任意字段列序的横向记录和已支持的报价百分比明细；兼容常见同义词及明确的单位标注，不保证任意企业表格都能识别。预览显示来源工作表、单元格、候选值和待补项；多表、多记录或字段冲突需选择后重新识别，成本单位不明时需人工核对。未识别或缺失输入留空，不从实际资料补理论。核对并编辑表单后点击“保存新理论版本并检查”，仍须通过完整输入校验。
4. 明确业务订单号及批次，并核对当前快照与理论基线的业务、数量期间、收入成本范围和税口径。勾选范围确认后才判断毛利偏差；不确认仍可保存目标。
5. 查看毛利率和累计不良率、差异、采用的规则、数据截至日期及检测时间。源表参考试算和预测继续显示试算标记，真实/模拟类型沿用原快照标记，不自动核实数据真实性。
6. 可将预警标为已确认、处理中或已关闭，并填写备注。人工处理不消除仍存在的异常；新的有效观测恢复后记录恢复状态。处理备注另存审计记录，可展开查看。

报价核价的备料、油压两项计件人工按订单数量计价，与生产经管比例一并计入「人工成本」这一项，成本构成里不再单列、也不重复累加；公司管理干部与行政费用列为经营费用，在计划生产毛利之后计算计划经营利润，仅作理论预算依据。物流不纳入本轮报价生产/经营预算，不表示实际物流为0；tax_basis=ignored标明“本次不计税”，不作税额调整。能源0.4%仅为待企业核实的样例比例。样例按钮只填比例，不自动绑定虚拟订单A-011。

当前税口径未知时，只有明确确认两侧采用相同口径，才作参考比较，仍提示税口径待核实。数量不一致、利润缺失、收入不大于零等情况不能通过勾选强行变成可比。整单预算不能直接与未完工过程的部分费用比较；首版没有自动预测剩余成本。

顶部“理论与实际对照”页签和首页摘要入口保留，左侧“工作空间”移除重复的理论对照入口。历史回看仍禁止导入和修改。

同时出现整单成本和报价百分比时，需明确确认采用当前选择的核价方式，切换方式后需重新确认。重选来源失败、文件超限或识别中关闭面板时，不沿用上一文件输入，也不能保存未完成的识别；可重新上传或选择改为手动填写。

自动预览和重新识别仅在内存读取，不写快照、基线、绑定或检测记录。公式不会执行；存在可读保存值时标明“缓存未经核实”，必要输入无缓存则留空等待人工补齐。派生利润只作参考，不替代网站独立成本核算。网站下载模板不含公式；线下公式样表只能在已支持布局范围内读取输入及缓存，不能据此认定公式已重算或业务数据已核实。文件仍限10MB，解压大小、工作表数及行列/单元格限制不放宽。

## 已确认毛利标准与暂定质量规则

新规则使用margin_mode=relative，计算（计划生产毛利率－实际生产毛利率）÷计划生产毛利率×100%。正计划毛利率且范围可比时，实际优于计划显示“优于计划”，status仍为normal。

| 相对下降              | 显示等级 | status  |
| --------------------- | -------- | ------- |
| 0%～10%（含10%）      | 正常     | normal  |
| 超过10%至20%（含20%） | 注意     | warning |
| 超过20%至30%（含30%） | 重点     | focus   |
| 超过30%               | 严重     | danger  |

10/20/30为右闭边界。页面和报告同时保留百分点差delta_pp，避免与相对下降百分比混淆。例如计划25%、实际20%，下降5个百分点，相对下降20%，归为注意。计划毛利率小于等于0时相对下降不适用，保留待补提示。

质量暂沿用累计不良率≥3%提醒、≥5%严重，累计生产观察量100，可修改。低于观察量展示实际比例并标记待观察；零产量、数量无效或缺少质量数据不会标为正常。日报不良/生产不等同最终报废率；报价中的不良品损耗成本1.8%是收入成本预算，不能当作不良数量率阈值。

规则编辑适用于后续检测，相对下降三阈值须递增。毛利标准已获用户确认；质量阈值仍为暂定，provisional保留质量规则的暂定标记。新安装默认使用新毛利标准；已有旧规则的本机服务须显式POST /api/comparison/rules保存新标准，并保留该服务当前质量阈值。保存不会覆盖旧检测，如需对当前数据采用新规则，点击“重新检查”。毛利与质量分别判定，严重、重点、注意依次优先；此前预警尚未得到有效正常观测时，不因新数据缺失而解除。

历史规则缺少margin_mode或为points时，继续按保存的margin_warning_pp/margin_danger_pp解释（原默认≥3/≥5个百分点），历史记录不迁移、不重写。过程对照必须保持同数量、同期间及相同成本覆盖范围；整单计划不能直接与未完工部分费用比较。

按产品/订单覆盖、最低绝对毛利率、单日和连续超标规则、预计完工利润及自动成本差异归因留作后续扩展。

## 自动检测、绑定和历史

- 成功导入并保存新实际快照时自动检测；全重复导入不新增对照或预警。
- 普通独立订单号只有业务编号相符、没有歧义批次、产品单位及已确认数量范围匹配时才自动沿用基线。比例型没有理论数量时记录最初确认的实际数量作为匹配边界，不反推出理论金额。
- SRC-款号不是独立业务编号，必须填写对应业务单号。SRC的新实际快照不会仅靠款号自动套理论，需要再次明确绑定；质量规则在有效数据下仍可独立检测。
- 同一业务订单号、同一批次重复导入理论只保留最新一次，旧版本删除、不累积；再次导入该订单时历史堆积会整体收敛。已保存的检测各自冻存当时的理论数字，删掉旧版本不改写历史，但也不能再绑定回旧版本；需要并存多套口径请用不同批次号区分。真实与模拟基线隔离，同款不同业务批次分别保存，不能跨类型绑定。
- 历史回看只展示保存时的基线、规则、事件和检测，可选择该快照的不同检测版本；旧快照没有检测时明确显示未检测，不自动重算。
- 趋势每个实际快照最多一个有效检测点，只到所选快照的数据截至范围；一个点不生成趋势。检测记录保留规则版本，多次重检不伪装为新增生产进度。
- 补录较旧数据不会产生当前新预警或解除较新预警。删除实际订单后，对照读取和处理同样阻止；恢复后原资料保留。
- 检测随实际数据更新发生，未接入现场/ERP自动同步。导入成功而辅助检测失败时明确提示“订单已保存，需重新检测”，不误报导入未保存。

## 存储与备份

所有新业务资料位于 reports/snapshots/comparison-data/，受现有Git忽略规则保护。包含 baselines、bindings、rules、settings、records、current-records、events、watermarks、handling 等子目录。备份整个 reports/snapshots，不能只备份latest.json。

基线、规则和检测记录保留版本；事件及处理状态单独保存。多文件写入使用持久化回滚日志transaction.json；失败回滚，进程中断后首次访问恢复未提交变更。不要人工删除未完成事务日志。原始实际计算快照不因理论设置而改写。
