# 计算及校验规则草案（历史）

**2026-10-13 更新：当前公式以 [利润计算公式 v0.2](formula_v0.2.md) 为准。以下保留初版背景，存在差异时服从 v0.2。**

本文用于团队确认口径，不代表规则已实现或已获得企业认可。

## 本次计算范围

生产毛利 = 订单收入 − 直接材料成本 − 直接人工成本 − 分摊制造费用。

毛利率 = 生产毛利 ÷ 订单收入。收入为零时不执行除法，返回不可计算及原因。

编码前确认价格、折扣和税口径；材料采用实际消耗还是 BOM 估算；补退料及损耗是否重复计入；人工归集方式；制造费用、模具和跨月订单的分摊方法。金额精度与舍入位置也由算例约定。

关键成本缺失不可默认为零。估算使用显式假设，并将结果标为估算；所有成本分项齐全且通过准入检查后才能标为可计算。保留公式版本、输入来源和计算截止时间。

## 初步校验规则

| 编号 | 检查内容 | 处理原则 |
| --- | --- | --- |
| D001 | 必填字段缺失 | 记录字段和来源，按利润影响决定是否阻止计算 |
| D002 | 来源单据行重复 | 依来源、单据及行标识判断，避免重复计入，保留原始证据 |
| D003 | 编号关联失败 | 保留待核验记录，不静默丢弃 |
| D004 | 格式、单位或范围不合理 | 提示核对；退料等合法负数按业务类型判断 |
| D005 | 材料实际消耗与理论用量差异 | 使用已确认的数量、BOM 版本及阈值；差异不直接等于错误 |
| D006 | 生产数量关系或期间冲突 | 考虑报废、返工、跨月与补录，保留核查依据 |
| B001 | 低毛利或负毛利 | 阈值由团队与企业确认，并随结果保留阈值版本 |

净领料候选公式为“领料 + 补料 − 退料”，前提是各类型未重复统计且正负号约定一致。理论用量的数量基准、差异容许范围均需确认。

检查结果区分通过、未通过、无法检查。数据可信状态为可信、待核验、异常、缺失；业务异常与计算可用状态分别保存。可信仅表示当前检查范围内证据充分，不是绝对真实性保证。

人工核查保存确认人、时间、证据、原因和修正版本，并重新执行受影响的校验与计算。

## 验收依据

由业务同伴提供至少一笔完整订单及手工结果，用于核对收入、各成本项、毛利和毛利率；另准备关键成本缺失、重复导入、关联失败和收入为零的样例。期望处理结果在实现前共同确认。
