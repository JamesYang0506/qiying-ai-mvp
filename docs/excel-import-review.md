# Excel 导入预览与确认

更新日期：2026-10-14。

## 使用方式

1. 在订单分析页面选择 Excel 文件，程序先显示读取预览，不保存计算快照。
2. 核对费用所在工作表、字段位置、读取数值和单位。按标签识别的字段自动提出位置；找不到标签时会标为模板位置，需重点核对。重复标签或不支持单位会提示处理。
3. 如位置或单位不符，可修改单元格坐标，选择元/双或元/整单，再点击重新预览。整单费用按本单数量换算；订单单价只支持元/双，折扣支持每双金额或整单金额，不直接读取折扣率。
4. 展开材料和生产日报读取区域，核对配方、SOP重量、尺码、数量、日期是否仍在这些区域中。
5. 勾选确认后点击确认并计算。只有此时才写入分析快照。关闭或取消预览保留当前分析。

标准模板按表头读取，允许列顺序变化。预览显示工作表、数据行数、表头和前3行样例；确认后执行原有完整性检查。

## 导入方案

可给方案命名并保存，下次选择方案后重新预览新文件。方案只保存工作表、字段位置和单位，不保存订单数值或文件内容。方案存于当前浏览器的本地存储，仅在相同网站地址下复用；更换浏览器、端口或清理浏览器数据后可能需要重新设置。最多保存20个方案。

## 支持边界

当前自动识别和手动调整覆盖中底成本布局中的订单数量、单价、折扣及17项加工/行政费用，支持成本工作表别名。原订单用量、补单用量、生产周期三张明细表仍需保留规定名称和预览显示的模板区域；任意材料或日报布局不是本次的通用支持范围。

公式按文件原有引用计算，映射位置调整不会改写原表公式。不支持的公式会提示，不以保存答案替代计算。外链费率仍采用原文件保存值并保留待核验状态。映射确认不证明业务凭证真实。

利润及已识别的费用汇总结果不能直接或间接作为成本输入。缺失费用继续保持未知，不补零。数量、单价和折扣必须明确提供，零折扣应填0。

## 可追溯结果

源表试算结果保留 import_review，包含原文件指纹、实际工作表、单元格、读取数值及确认单位。详细数据页可展开本次确认的读取位置；历史快照也保留这些信息。底层金额计算继续使用 Decimal。

## 接口

- POST /api/preview-xlsx：JSON携带 workbook_base64 和可选 mapping，返回只读预览及 source_hash。
- POST /api/import-reviewed-xlsx：携带同一文件、mapping、source_hash、confirmed=true，服务端重新校验文件指纹和映射后计算。
- 原 /api/import-xlsx 保留为旧版接口；当前网页的 Excel 导入统一走预览确认流程。JSON标准输入继续沿用直接导入。

已用合成工作簿验证移动费用位置、同义标签、重复标签、整单换算、重复小数精度、利润和移动汇总排除、文件指纹、复用方案读取新值、成本工作表别名及标准模板列重排。浏览器验证包括预览和取消不写记录、确认后单次保存、来源追溯及手机布局。
