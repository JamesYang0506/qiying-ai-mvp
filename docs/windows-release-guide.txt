企盈智擎 v0.3.0 Windows 免安装版

使用方法
1. 将下载的 ZIP 完整解压到一个文件夹，不要在压缩包内直接运行。
2. 双击 QiYingProfit.exe，浏览器会自动打开本地网站。
3. 保持启动窗口打开，关闭该窗口或按 Ctrl+C 即可退出。
4. 点击“导入数据”导入获准使用的 Excel 或 JSON；首次使用没有企业数据。
5. 网站自动选择空闲端口，不需要自行配置端口。

运行要求
Windows 10/11 64位；不需要另外安装 Python、Node.js 或 Excel。
成本计算、图表、可信化审查、Excel导入及结果导出可直接使用。
本软件未附带企业订单、模型权重或个人凭证。
