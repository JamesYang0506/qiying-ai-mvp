# 利润计算公式 v0.2

优先依据：2026-10-13《企盈智擎_算法公式与说明汇总(1).docx》。历史交底书及 v0.1 说明仅用于追溯。

| 项目 | 当前公式与条件 |
| --- | --- |
| 行收入 | R_ij=P_ij×Q_ij−D_ij；原则上不含税，折扣缺失不可填零 |
| 订单收入 | R_i=ΣR_ij；存在 order_lines 时按行汇总，不重复加订单头收入；数量及单位须匹配 |
| BOM材料 | ΣQ_m×P_m/(1−L_m)；损耗率0≤L<1、定义确认且未重复包含；缺失时不猜参数 |
| 实际领用材料 | ΣA_m×P_m；领补退料、结余及在制品口径先确认；不再加损耗 |
| 人工 | ΣW_k×Y_ik；需工段计件单价与应计薪数量，不能擅自按产量平均分摊工资 |
| 制造费用 | Σ_t(M_t/H_t×h_it)；费用池、完整工时分母、订单工时与期间一致，缺失阻止计算 |
| 模具摊销 | 当前禁用；客户提供模具不代表其他制造费用为零 |
| 生产毛利 | GP=R−材料−人工−制造费用；企业确认的其他生产成本单独归集并披露，不重复扣减 |
| 单位毛利 | GP/Q，要求Q>0且数量单位可比 |
| 毛利率 | GP/R，要求R>0；否则返回null |
| 订单管理利润 | 毛利−已确认归属的管理/销售/财务及其他订单费用；默认关闭，明确 metadata.management_enabled=true 才启用；不是财务报表净利润 |

收入税口径待确认而复算原表时设置 revenue_status=estimated，不自动推算税率。收入、成本范围不一致或未确认，正式利润不能标为完整。

## 中底源表适配口径

材料表使用 `SOP每双重量×对应码号数量`，配方均价为 `Σ(配方用量×单价)/Σ配方用量`。这属于源表标准用量估算，不能直接认作采购加权均价或实际净耗用，也不虚构损耗率套入 BOM。

`源表毛利/双=折后单价−材料/双−加工费/双`。

`源表参考利润/双=源表毛利/双−行政费/双`。

两者保存在 source_analysis 中，与正式利润分开。本地公式用受限解析器重新计算；外链只读已有缓存，未提供原表前逐项标为待核验。缓存缺失或必要费用空白时，受影响的参考利润留空。

工资、制造费用和行政分摊依据不足时，不用参考费率冒充已经验证的计件/工时分摊。按日期、码号检查生产与不良数量，再核对补单；差异保留，不自动补料或改账。

## 追溯与精度

保留工作表、单元格、源公式、复算/缓存标记、原文件哈希、快照与待核验清单。不执行宏或自动连接外部工作簿。

未知不等于零，暂估不等于已确认。实际/预测分开展示。单项成本按分入账；与源表先汇总再舍入有差异时记录调整。分摊按整数分最大余数法处理，保证非负和守恒。
