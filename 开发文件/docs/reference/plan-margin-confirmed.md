# 计划与实际毛利对照确认口径

来源：用户2026-10-16对企业订单流程的回复。本文件记录已确认需求；当前源码已接入四级相对下降规则与报价比例核价schema。新安装默认使用新规则；已有服务须显式保存新rules并保留当前质量阈值，历史检测不迁移。

## 已确认

- 主指标为生产毛利率，比较公式：（计划毛利率－实际毛利率）÷计划毛利率。
- 实际优于计划显示“优于计划”。边界向下归档：0%～10%正常，超过10%至20%注意，超过20%至30%重点，超过30%严重。
- 预算中的成本百分比以报价收入为基数；材料比例不包含生产损耗和不良品损耗，二者单独列支。
- 能源按报价的0.4%暂建样表。用户用语为“应该是0.4%”，仍须企业最终核实。
- 公司管理干部与行政费用作为经营费用，单列于生产毛利之后；不混入生产毛利率。
- 计划没有物流时，本轮计划排除物流，不表示实际物流已确认是0；本轮不考虑税。
- 没有正式样表，先按提供的虚拟订单参数建立可编辑计划核价表。

## 样表结果与缺失值

虚拟订单已知生产成本比例为70.6%，扣计件人工前毛利率为29.4%。两项计件人工尚无单价，因此29.4%不能作为完整计划基线。完整计划毛利率须在两项人工填齐后计算；明确确认无需该人工时才允许填0。

样表包含“计划核价”和“毛利对照”两页。实际毛利率留空，只有完整计划与实际毛利率均可用、且人工确认可比范围后才判断等级。计划毛利率小于等于0时，相对下降比例不适用，规则另行确认。工作簿含公式，用于线下核价；网站只读自动预览可在已支持布局内识别输入与保存缓存，多表、多记录或字段冲突须人工选择。公式不执行，可读缓存显示“缓存未经核实”，必要输入无缓存则留空待补，不保证识别任意Excel或直接验证整个公式样表；网站另提供不含公式的输入模板。派生毛利只作参考，不能替代网站独立成本核算。报价输入采用method=quote，百分比以报价收入为基数按0～100输入，两项人工空白不可保存、0允许。经营费用单列，仅作计划预算，不修改actual公司费用。自动预览不改变四级毛利标准或旧历史检测语义。

质量规则仍沿用暂定数量不良率阈值。报价不良品损耗成本1.8%不等于不良数量率，不用于质量预警阈值。过程比较须同数量、同期间及同成本覆盖范围；本轮tax_basis=ignored标记“本次不计税”，不作税额调整。
