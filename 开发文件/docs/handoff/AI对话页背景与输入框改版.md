# AI对话页背景与输入框改版

日期：2026-10-19。

按用户要求暂停场景回答文档，优先调整AI界面。本轮没有修改模型、回答规则或利润计算。

## 界面变化

- AI页与前四个模块共享 `monitorMasthead()`、蓝色侧栏、浅色主背景，保留统一Logo与中英文控件。
- 参考所提供对话框，改为居中欢迎语、宽幅圆角输入框、右下圆形发送按钮与下方快捷问题。
- 日期与订单选择放入输入框底部，原侧边上下文栏收进“分析范围与使用说明”，减少首屏信息密度。
- 模型离线状态和重新检测入口保留，模型未启动时不能发送；不添加尚无对应功能的深度思考或搜索按钮。
- 有消息后显示可滚动聊天记录，保持多轮追问、切换范围清空旧对话、页面退出取消请求及HTML文本转义。
- 样式限定在 `.ai-page` 内，支持窄屏控件换行与减少动画偏好，不修改其他模块的业务样式。

## 修改文件

`dist/app.js`、`dist/ai-page.js`、`dist/ai.css`、`dist/project-i18n.js`、`tests/ai-client.test.mjs`。

前端静态文件直接由现有服务读取，无须更改后端运行包；刷新AI页面即可加载。

## 验证

- 全量自动测试185项通过；新增渲染测试验证范围值、草稿转义和离线发送状态。
- 调整日期与订单的显式无障碍标签后，对AI客户端和双语相关8项测试重新验证通过。
- 浏览器使用独立模拟数据和明确标记的联调服务，验证日期、订单选择、两轮流式问答和历史传递。
- 浏览器验证离线提示、快捷问题填入、重新检测保留草稿、模块导航和中英文切换。
- 本次没有启动真实模型或写入真实订单；远程模型对接状态保持原状。
