## 使用与限制

访问 `http://127.0.0.1:8787/#register` 创建自己的账号，然后登录。账号存于本机 `data/imports/auth/accounts.json`，该目录已被 Git 忽略。本次没有导入协作者的账号或设置默认账号。

会话存在服务器内存中，重启需重新登录；已注册账号保留。“保持登录”的会话有效期为七天，但不跨服务重启恢复。

这是本机共享工作空间的登录系统，所有已登录账号仍能访问同一批订单。企业、角色、订单范围、敏感字段权限、邮箱验证和找回密码未在本次新增，不能将本次合并视为已完成多人数据隔离。AI 协作版内容也未在本次合入。
