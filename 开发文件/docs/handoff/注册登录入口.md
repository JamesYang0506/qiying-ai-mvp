# 注册登录入口

## 使用

关闭旧的网站服务窗口，重新运行“启动网站.cmd”，浏览器 Ctrl+F5 刷新。首次使用选择“注册”，创建账号并输入图形验证码，成功后登录。根地址登录后默认进入数据导入；从订单监测、订单分析等链接进入时，登录后返回原链接。

页面采用用户提供的企盈智擎图片 Logo、浅蓝雾化背景、玻璃卡片、常规账号密码表单和中英文切换。注册登录页与业务页面共享语言偏好；业务页面支持中文 / EN 切换。图形验证码可点击换图，忽略字母大小写。

## 账号与访问

- 新增 /api/auth/captcha、register、login、session、logout 接口。
- 账号保存在 data/imports/auth/accounts.json，使用独立随机盐及 scrypt 密码摘要，不保存明文密码。
- 正常启动默认启用服务端登录检查，未登录无法访问 /api/import-v1 或 /api/v1 业务接口；直接修改 URL 不授予访问权限。
- 登录使用 HttpOnly、SameSite=Strict Cookie，服务端会话 12 小时；勾选保持登录为 7 天。服务端进程重启后须重新登录，已注册账号保留。
- 验证码有效期 5 分钟，每次提交后失效；账号接口与验证码有请求频率限制，并检查写入请求来源。
- 业务页新增退出登录入口；会话过期时引导重新登录。
- 这是本机工作空间账号体系，注册账号共享本机现有订单数据；未添加企业隔离、邮箱验证或找回密码服务。
- authRequired:false 仅用于独立业务回归测试服务；正常 serve.mjs 不关闭登录检查。
