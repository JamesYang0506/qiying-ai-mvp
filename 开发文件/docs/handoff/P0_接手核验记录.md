## 发现与说明

1. 直接向仓库 `data/imports/` 重新导入本机案例时返回 409「同一修订号内容已改变」。原因：`A011_每日生产材料费用案例_v0.2.xlsx` 的修改时间（2026-10-17 09:28）晚于已保存版本（06:39），内容有两个字段的浮点表示差异（`materials[0].net`、`expenses[57].amount`）。这是“同修订内容冲突拒绝”的预期行为，不是回归；隔离目录导入验证通过。是否把新文件作为新修订/新基线导入，需业务确认。
2. 交接文档沿用 Node 20.20.2 结果；本机实际 Node 24.17.0 下测试与案例全部通过。
3. 8788 端口已有交接前启动的实例（PID 42256），本轮未终止，也未使用该实例做写入验证。
