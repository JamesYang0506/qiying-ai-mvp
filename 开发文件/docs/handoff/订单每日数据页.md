# 订单每日数据页

第二项导航“订单详细数据”改为独立的 #data 页面，不再复用已导入订单的利润概览、差距归因和明细标签。

- 按订单、资料版本、业务日期选择，支持上一天/下一天和每日卡片跳转；切换订单恢复其开工日，切换版本保留业务日期。
- 当日合格产量、生产成本、生产毛利直接读取原 analysis 接口的 daily 字段，未新写利润公式。
- 原始生产记录、材料净耗及单价、人工/制造/经营费用、补单原因/数量/关联记录/计入口径分别列出，标注原始 Excel 文件角色、工作表和单元格。
- 补单仅展示原始记录，不重复计入生产或成本；缺项保留未知，不伪造零金额；无记录时明确显示。
- 沿用监测首页的蓝色顶栏、深蓝导航、白色卡片和条纹表格；仅 #data 页面启用此样式。
- 订单监测、数据导入、已导入订单及其归因分析未调整。

验证：88 项 Node 测试通过；新增每日页面浏览器验证（日期、订单、版本、补单、Excel 来源、手机布局），原监测及已导入订单浏览器回归通过。浏览器验证使用临时测试数据，不修改真实导入资料。
