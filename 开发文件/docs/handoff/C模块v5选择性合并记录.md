## 对接接口

以下接口均经过主站既有登录校验；POST同时检查Origin。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/v1/ai/status` | 模型服务连接状态、模型与内存信息 |
| `GET /api/v1/ai/models` | 模型列表与可用性 |
| `POST /api/v1/ai/answer` | 订单业务问答，SSE流式响应 |
| `POST /api/v1/ai/chat` | 通用非流式对话 |
| `POST /api/v1/ai/chat/stream` | 通用流式对话 |
| `POST /api/v1/ai/json` | 结构化JSON输出 |

订单问答请求：

```json
{
  "question": "与预期相比少赚了多少？",
  "history": [{"role":"user","content":"前一个问题"},{"role":"assistant","content":"前一个回答"}],
  "asOf": "2026-10-18",
  "orderId": ""
}
```

`orderId`为空表示全部已导入订单。业务日期为空时取服务端北京时间当天。修改范围会清空当前页面对话，防止旧订单上下文混用；不持久化聊天记录或监测快照。

## 相对协作版的兼容修正

- 原摘要只读取最新一个导入文件，并把未来生产量也累加。本次改为每个订单的最新修订，调用现有 `evaluate()` 核算选定日期的数据，不另写利润公式。明确区分实际累计毛利、同进度理论毛利、全订单理论最大毛利及未结算利润；缺失金额保持未知。
- 摘要最多约5000字符，缓存最多8个范围、有效期30秒；导入修订立即改变缓存键。截断时标明已包含订单数，不能据此推断完整排名。全过程不读取历史快照池、不新增归档。
- 原前端每次传空history，本次传最近成功对话；异常或不完整回答不会成为后续已确认上下文。
- 处理中文UTF-8跨包和SSE结束标记；生成中途报错或连接意外结束，保留已显示文字并明确标为回答未完成。
- 用户与模型文本都经过HTML转义；模型返回HTML不作为页面元素执行。
- 页面离开会取消浏览器请求；浏览器断开后，服务端取消正在读取的上游流。
- 上游未启动时返回真实离线状态，允许重新检测，不显示模拟业务答案。

## 真实模型服务仍需单独启动

这份协作项目包含主站对接代码，**不包含独立的企盈AI服务、模型权重、知识库或信令控制台**。

默认上游地址为 `http://127.0.0.1:3320`。主站适配器预期上游支持：`GET /api/health`、`GET /api/models`、`POST /api/chat`、`POST /api/complete`、`POST /api/json`。

启动时可通过环境变量 `QIYING_AI_BASE` 配置协作方提供的服务地址；没有配置则使用上述本机地址。不要把它直接指向普通Ollama端口，因为本适配器使用的是企盈AI服务的协议。

本次检查时，本机3320端口没有服务响应。因此本次完成的是代码整合、接口及页面联调，不代表真实模型已运行或模型回答质量已验收。需要协作方提供对应企盈AI服务程序与启动方法，运行后在主站AI对话页点“重新检测”。

来源版本登记 `gpt-oss:20b` 和 `qwen3.5:9b`，别名与内存参数保留其策略；本次没有下载或训练模型，也没有自动启动知识库。
